# Snowline Lyrics 0.4.2 · Preview

从 0.3.0 升级：
- 新增背景颜色、背景图片、背景透明度和歌词颜色设置。
- 新增黑／白背景遮罩、0–100% 强度、35% 快捷选项及文字阴影开关。
- 设置按外观、播放、歌词源、关于分组。
- 显示已保存的背景图片名；标题、按钮及状态文字跟随歌词颜色。
- 外观设置仅保存本机，旧配置兼容，遮罩及阴影默认关闭。

## 下载和升级
下载 `Snowline-Lyrics-0.4.2-win-x64.zip`，完整解压后运行 `SnowlineLyrics.exe`。
升级前先在托盘退出旧版；已有歌词缓存及外观设置会保留。不需要安装 Node.js 或浏览器扩展。

Windows 10/11 x64 便携预览版，未签名；已在 Windows 11 测试。播放器需提供 Windows 媒体会话信息。
