# Snowline Lyrics 0.3.0 — Preview

新增免费、免账号的 LrcApi 公共第二同步源。LRCLIB 没有明确时间戳匹配（包括只有普通歌词）或失败时，可继续查找其他同步候选。

使用方法：设置 → 第二同步歌词来源 → 勾选“允许 LrcApi 公共同步源” → ↻ 重查 → 确认候选版本。默认关闭，开启后无需账号、API Key、付费订阅或部署。

查询优先级为 LRCLIB → 可选 LrcApi 同步源 → 可选 lyrics.ovh 普通歌词。保留已有的手动选定或导入内容，不会无提示覆盖。LrcApi 候选保留服务返回的歌曲、歌手、专辑信息，必须确认后采用。

继续支持自动同步、无进度手动对齐、普通歌词全文滚动、本地 LRC/TXT 导入、托盘和窗口设置。

升级前先从托盘退出旧版，完整解压 Snowline-Lyrics-0.3.0-win-x64.zip，双击 SnowlineLyrics.exe。数据目录不变。

Windows x64 未签名测试版，无自动更新。公开接口的覆盖、速度、版本正确性与持续可用性不保证，未来可能改变要求。不会自动转用付费服务。手动计时可能漂移，音乐跳转后需重新对齐。

两首实际歌曲的公开端点探测返回了时间戳 LRC，实际 JSON 客户端也解析到多个同步候选；这不代表所有歌曲都支持。UI 测试使用原创模拟歌词，没有把真实歌词打包。QQ 音乐等客户端和 Windows 10 仍待各自验证。

不开启的备用来源不会收到查询。开启后 LrcApi 接收歌名和歌手，具体隐私和来源说明见仓库文档。本项目只调用公共 HTTP API，不捆绑服务端代码；MIT 代码许可不授权第三方歌词内容。
