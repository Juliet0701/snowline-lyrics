# Snowline Lyrics 0.7.0 · Preview

## 中文

- 歌曲下方新增「修改搜索关键词」：可编辑歌名和歌手搜索，候选结果由用户确认；可恢复播放器原信息。
- 选定歌词版本、搜索关键词与时间偏移按歌曲保存在本机，切歌及重启后恢复。
- 外观设置可独立调整当前句、下一句字号，支持恢复默认。自定义字号不随窗口大小变化；未调整时保持旧版字体表现。
- 同时包含 0.6.1 的设置窗口最小化恢复修复。
- 保留现有配置和旧版程序。歌曲按播放器提供的歌名、歌手、时长识别，不同信息可能对应不同记录。

先从托盘退出旧版，完整解压 Windows 便携包，再运行 SnowlineLyrics.exe。

## English

- Edit song title and artist search keywords, confirm a lyric version, or restore original player metadata without renaming the playing track.
- Remember selected lyric versions, search keywords and timing offsets per song across track changes and restarts.
- Adjust current/next-line font sizes independently. Custom sizes stay fixed during window resizing; untouched defaults preserve the existing typography.
- Includes the minimized Settings restoration fix from 0.6.1.
- Existing preferences and older versions are preserved. Song identity uses player title, artist and duration; different metadata may have separate saved choices.

Exit the old version from its tray menu, fully extract the Windows portable ZIP, then run SnowlineLyrics.exe.
